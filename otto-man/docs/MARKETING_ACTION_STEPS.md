# Marketing — Exact Steps

Companion to MARKETING_PLAN.md (that file has the reasoning/strategy — this
one is just the literal do-this-now sequence). Do these in order.

---

### 1. Create your Steamworks account and register the app

1. Go to `partner.steamgames.com` and sign in with the Steam account you want
   permanently tied to this game (needs Steam Guard on, in good standing).
2. Accept the Steamworks Distribution Agreement when prompted.
3. In the partner dashboard, find "Register a New App" (under the App Admin /
   My Apps area). Click it.
4. Pay the one-time $100 USD Steam Direct fee for this app. It's recoupable —
   Valve refunds it once the game hits $1,000 in sales.
5. This creates a draft App ID — this is now your control panel for
   everything else on Steam for this game.

Now your Steamworks app exists and you have a place to upload into.

*(Note: Valve tweaks the exact wording/layout of this dashboard occasionally —
if a label doesn't match exactly, look for the closest equivalent section;
the flow itself has been stable for years.)*

### 2. Get the art assets into that App Admin panel

1. Get the checklist from MARKETING_PLAN.md Phase 1 (logo, capsules,
   screenshots, trailer) to Goku, in that priority order — logo + one capsule
   first, so you can start Step 3 below without waiting on everything.
2. As each piece comes in, upload it in your App Admin under the store-assets
   section (labeled something like "Store Page Assets" / "Edit Store Page").
3. Upload screenshots as they're ready (need 5 minimum, real gameplay).
4. Upload the trailer link last, once you have one hosted on YouTube.

Now your app has real assets attached instead of placeholders.

### 3. Write and submit the store page

1. In App Admin, open "Edit Store Page."
2. Fill in: game name, short description, long description, genre tags
   (include the ones that actually apply — search Steam for 2-3 similar games
   and copy the tag style, not the tags themselves).
3. Fill out the Content Survey honestly (mature content descriptors, AI-use
   disclosure section) — required before the page can go live.
4. Click "Submit for Review" once every required field is filled.
5. Expect a wait — first-time pages can take 2+ weeks for Valve to review.
   Nothing to do here but wait once submitted.

Now your Steam page is in Valve's review queue. Once approved, it's live and
wishlist-able — this is the CTA every future piece of content points to.

### 4. Set up the Discord server

1. Open Discord, click the `+` at the bottom of your server list.
2. Choose "Create My Own" → "For a club or community."
3. Name it after the game (fine to rename later if the title changes).
4. Create these channels:
   - `#welcome-and-rules`
   - `#announcements` (Server Settings → permissions → only you/mods can post)
   - `#general-chat`
   - `#screenshots-and-fanart`
   - `#suggestions`
   - `#bug-reports`
   - `#dev-log` (your process posts — sketches, WIP shots, etc.)
5. If you want a channel for the more expressive character art: create it,
   then in that channel's settings toggle "Age-Restricted Channel" — Discord
   requires this for suggestive content, it's a per-channel switch.

Now you have a community home base ready for when the Steam page goes live —
don't publicize it until then, nothing to gather people around yet.

### 5. Create your content accounts

Hold off on this step until the title is locked (Step 3's page reveals it) —
avoid squatting a public handle under a name that might still change.

1. Create matching-handle accounts on: X/Twitter, TikTok, YouTube, Instagram.
2. Create a Reddit account if you don't already use one publicly for this.
3. Create an itch.io page (can be a simple placeholder initially, expand
   later per MARKETING_PLAN Phase 3).
4. Use the exact same handle/display name everywhere it's available.

Now you have one identity across every platform, ready to post under.

### 6. Produce your first batch of content

1. During your current full-time week, film raw footage for 3-5 Shorts using
   the template from MARKETING_PLAN Phase 3 (comment → test in-game → funny
   result → CTA) — capture raw clips now even if you edit them later.
2. Pull your first 5 real-gameplay screenshots while you're at it — reuse the
   best ones for both Steam (Step 2) and social posts.
3. Edit and schedule the first 2-3 posts to go out once the Steam page is
   live (Step 3 approval) — don't publish before the CTA destination exists.

Now you have a content backlog ready to deploy the moment the Steam page goes
live, instead of starting from zero at that point.
