8. NVIDIA CUDA RUNTIME LIBRARIES
----------------------------------------------------------------------------
This game distributes the following NVIDIA CUDA runtime libraries so that the
optional AI Villagers feature can use the GPU without the player having to
install the CUDA Toolkit:

    cudart64_12.dll     (CUDA Runtime)
    cublas64_12.dll     (cuBLAS)
    cublasLt64_12.dll   (cuBLASLt, required by cuBLAS)

    Copyright (c) NVIDIA Corporation. All rights reserved.

These are redistributable components under the NVIDIA CUDA Toolkit End User
License Agreement, which explicitly permits redistributing the listed runtime
libraries as part of an application:
https://docs.nvidia.com/cuda/eula/

They are NOT part of llama.cpp or LLamaSharp; those ship only ggml-cuda.dll,
which imports the three libraries above. Without them the CUDA backend cannot
load on a machine that has an NVIDIA driver but no CUDA Toolkit, and inference
falls back to CPU — unusably slow for a 12B model.

  [ ] If the CUDA version is ever changed, re-check the EULA's redistributable
      list for that version and update the filenames above.

The game's UI font, shipped as assets/fonts/main_font.ttf, is Grenze. The
display font for titles, shipped as assets/fonts/title_font.ttf, is Grenze

axis.

    Copyright 2019, The Grenze Project Authors
    (https://github.com/Omnibus-Type/Grenze)

    Copyright 2020 The Grenze Gotisch Project Authors
    (https://github.com/Omnibus-Type/Grenze-Gotisch)

Neither declares a Reserved Font Name, so renaming the files for use in this
project is permitted. Verified 2026-08-26 by reading both OFL.txt files: the
only occurrence of the phrase "Reserved Font Name" is in the license's own
definitions section, not appended to either copyright line. The OFL requires
that the copyright notices above and the full license text below accompany the
fonts wherever they are distributed, which is why both are reproduced here.

Obtained from the official Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/grenze
https://github.com/google/fonts/tree/main/ofl/grenzegotisch

HISTORY 1: these replaced Pixelify Sans (Copyright 2021 The Pixelify Sans
Project Authors, OFL 1.1, https://github.com/eifetx/Pixelify-Sans), which
shipped as main_font.ttf until 2026-08-26. That font carried no legal problem;
it was replaced because it was unreadable at the small sizes this project's UI
uses and because its "5" glyph reads as an "S".
